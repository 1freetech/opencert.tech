# Open Source Semiconductor Engineer Certification (OSSEC)

**Rotation key:** `semiconductor_engineer`  
**Status:** active  
**Starting lesson:** `OSSEC.001`

Engineering-level semiconductor lessons covering device physics, process integration, lithography, deposition, etch, diffusion/implant, yield, statistical process control, reliability, failure analysis, process windows, and equipment/process optimization.

Use filenames in the form `lesson-001-<topic-slug>.md`. Engineer lessons build on technician-level operating knowledge and focus on analysis, design decisions, tradeoffs, modeling, and process improvement.
