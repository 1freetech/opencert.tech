# Open Source Data Center Technician Certification (OSDCTC)

**Rotation key:** `data_center_technician`  
**Status:** active  
**Starting lesson:** `OSDCTC.001`

Hands-on data-center lessons covering rack-and-stack, copper and fiber cabling, labeling, server components, network links, power distribution, cooling awareness, hardware replacement, LOTO/ESD, console access, ticketing, and structured troubleshooting.

Use filenames in the form `lesson-001-<topic-slug>.md`. Technician lessons emphasize safe field execution, verification, documentation, and restoring service.
