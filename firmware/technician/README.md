# Open Source Firmware Technician Certification (OSFTC)

**Rotation key:** `firmware_technician`  
**Status:** active  
**Starting lesson:** `OSFTC.001`

Hands-on firmware-support lessons covering firmware images, version identification, safe flashing, bootloaders, serial consoles, recovery modes, configuration backup, logs, checksums, rollback, hardware/firmware compatibility, and field validation.

Use filenames in the form `lesson-001-<topic-slug>.md`. Technician lessons emphasize controlled change, recovery, evidence collection, repeatable procedures, and avoiding device bricking.
