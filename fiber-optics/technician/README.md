# Open Source Fiber Optics Technician Certification (OSFOTC)

**Rotation key:** `fiber_optics_technician`  
**Status:** active  
**Starting lesson:** `OSFOTC.001`

Hands-on fiber lessons covering connector types, cleaning, inspection, polarity, patching, bend radius, loss budgets at a practical level, visual fault locating, optical power meters, OLTS/OTDR basics, splicing, labeling, and safety.

Use filenames in the form `lesson-001-<topic-slug>.md`. Technician lessons emphasize cleanliness, handling discipline, measurement, installation quality, and fault isolation.
